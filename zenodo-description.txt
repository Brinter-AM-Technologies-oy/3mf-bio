DESCRIPTION
An open schema, built on the 3MF package format, for recording biofabrication work end to end
in a single file: material identity and synthesis route, cell provenance and authentication,
formulation and rheology, print process across twenty modalities, deposition heads and
nozzles, calibration events, staged post-print maturation with bioreactor and stimulation
regimes, and assays measured over a timecourse.

Its organising constraint is that every numeric parameter must declare where its value came
from - measured, derived, cited, vendor or estimated - enforced by XML Schema, ISO Schematron
and a reference validator. Fabricating a number requires labelling it as an estimate, which a
reviewer or a release gate can filter on, and every estimated value must be owned by an open
item recording what would close it.

It is not a standard and asserts no acceptance thresholds: no viability floor, no endotoxin
limit, no dimensional tolerance. It supplies the fields so that laboratories and manufacturers
can record against their own criteria and their own roadmap. Filling those fields is not
compliance and this project does not claim otherwise.

Not affiliated with the 3MF Consortium. It follows their schema conventions so that packages
remain readable by ordinary 3MF tools.

Pre-1.0 working draft. No real dataset has yet been recorded in this schema; see
review/DATASET-SHEET.md for exactly what would close that gap.
